# SAS Bulletin Task Monitor

A task monitoring and analytics dashboard for SAS Bulletin.

The application connects to ClickUp and automatically calculates task
assignments, completion status, member statistics, and monthly activity.

## Features

- ClickUp task synchronization
- Member task statistics
- Completed and active task counts
- Monthly task filtering
- Task search and filtering
- Member task details
- Reports
- CSV export
- Dark mode
- Automatic data refresh

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Express
- ClickUp API
- Recharts
